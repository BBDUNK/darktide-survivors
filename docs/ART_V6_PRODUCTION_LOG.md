# 《暗黑逃跑神》V6 美术资源生产与接入日志

> 状态：美术优先阶段。此阶段只生产、校验和归档美术，不接入玩法代码。
>
> 风格基线：细腻、写实、复古中世纪暗黑像素；不做 Q 版。所有角色、怪物、Boss、弹幕、地图与 UI 使用同一左上主光源、深紫黑轮廓和低饱和旧金属色。

## 1. 目录与交付层级

- `assets/art-v6/sources/`：Image2/GPT Image 生成的高分辨率母版、色键源图和人工选定参考。不可直接由运行时代码加载。
- `assets/art-v6/production/`：从同一母版派生并人工检查过的逐帧动作源图。每个动作一个横向 strip。
- `assets/art-v6/game-ready/`：完成硬 Alpha、逻辑分辨率缩放、调色板量化、锚点校准后的最终 PNG。
- `assets/art-v6/previews/`：1×、8×、16×预览和动作 GIF/WebM，只用于验收。
- `assets/art-v6/reports/`：逐帧覆盖率、脚底漂移、空帧、重复帧、边缘污染和人工验收记录。

资源只有同时满足以下条件才能标记为 `READY`：主体未裁切、动作帧完整、尺寸稳定、方向正确、无脏像素、Alpha 合格、预览通过、接入说明完整。

状态值：`TODO` 未生成；`SOURCE` 母版已生成；`FRAMES` 动作源图完成；`READY` 可接图集；`INTEGRATED` 已实装。

- 非光效素材 Alpha 只能为 0/255；光效可保留分级 Alpha，但边缘不得带色键残留。

- 左右动作必须真正确认朝向；允许在美术审核通过后镜像复用，但带盾牌、武器手和非对称装备的角色不得直接镜像。
- 地面光环只在地面平面展开，禁止单轴压扁圆形素材。
- 一次性特效播放到最后一帧后销毁；禁止回到第一帧循环造成“反复碎裂/反复爆炸”。
- 图集切片四周保留 1 像素挤出，运行时只用最近邻缩放。

## 11. 接入交接规则

后续代码模型接入任一资源前必须：

1. 只读取 `game-ready`，不得直接加载 `sources`。
2. 在图集清单登记 `name/source/frameSize/frames/fps/size/anchor/renderScale`。
3. 动画起播由实体动作开始 Tick 决定；联机快照只同步状态名、方向和开始 Tick，不能按快照到达次数切帧。
4. 瞬时 VFX 使用可靠事件触发；持续尾迹由客户端按确定性种子生成。
5. 地面特效、地板和道路在角色下；武器、剑气和前景命中特效在角色前；虚影在角色身体后。
6. 逐项运行图集质量检查、动作预览、单机实机、双浏览器联机和手机尺寸截图。
