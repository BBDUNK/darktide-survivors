# 参考来源与使用边界

本资源库里的 `generated/` 都是本次为项目生成的原创概念图；没有下载、裁切或再发布下列第三方素材。

- [Ninja Adventure Asset Pack](https://pixel-boy.itch.io/ninja-adventure-asset-pack)：研究俯视角单位、UI、tile 的统一像素密度与可读性。页面说明其采用 CC0；若未来实际引入其中任何文件，须另行记录文件名与来源。
- [Tiny RPG - Mana Soul GUI](https://opengameart.org/content/tiny-rpg-mana-soul-gui)：研究小尺寸 RPG UI 的信息层级与边框对比；不复制任何图样。
- [Pixel-art animation walk-cycle guide](https://pixnote.net/en/learn/animation/)：用于动作节奏、接触/下沉/经过/抬升关键姿势的检查。

这些页面仅作设计与动画方法参考，不能视为本库的再授权。正式导入第三方文件前，必须核验每个文件的许可证、署名要求和分发条件。
