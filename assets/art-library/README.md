# Darktide Survivors — 美术资源库（未接入）

这是为本项目准备的第二套完整美术生产库。它**不会被游戏读取**：没有改动 `js/`、`index.html`、`assets/sprites/atlas.json` 或现有图集。它的用途是将风格、资产范围、动画规格和供其他 AI 使用的提示词一次交接清楚。

## 快速使用

1. 先把 `generated/` 中的概念板作为视觉参考，不直接裁图进游戏。
2. 选对应的 `prompts/*.md`，一次只生成一个角色/物品/动作；始终以同一张角色母版作参考。
3. 按 `art-manifest.json` 的尺寸、帧数、枢轴和命名交付 PNG 帧或图集。
4. 用现有 `tools/art/pixel-cleanup.py`、`validate-sprites.py` 做像素清理与验收；确认后才新开一次“接入”任务。

## 艺术方向

原创的俯视角暗黑奇幻“幸存者”游戏：古老墓园、紫蓝迷雾、铁器与骨质怪物。风格是成熟比例、细腻而冷峻的复古暗黑像素，允许恐怖与压迫感，但不是 Q 版、圆润卡通或写实恐怖。轮廓利落、低饱和石色与冷青色为底，技能使用清晰的金色、猩红、青蓝作高亮。不要模仿或复刻任何商业游戏的具体人物、图案或素材。

- 主视觉像素密度：角色/敌人 24×24 逻辑像素，Boss 48×48；先在 48×48 / 96×96 母版绘制再确定性缩小。
- 透视：俯视 3/4，面向下方；主光源来自左上。
- 描边：1 逻辑像素深靛色硬边；禁止模糊、半透明抗锯齿与摄影质感。
- 调色：每个小型单位 7–11 个主体色；全局 30 色以内；发光只用于可交互/攻击信息。
- 可读性：敌人先看轮廓和色块，再看细节；同屏数百个单位仍要一眼区分。
- 动画：所有逐帧以脚底/悬浮中心为固定枢轴；极值帧必须有至少 1 像素的挤压、拉伸或重心位移，不能只是贴图抖动。

## 交付约定

每个可动画资产须交付 `idle`、`move`、`attack`、`hurt`、`death`（按清单适用），每帧单 PNG 或统一等宽横排。文件示例：`char_knight_run_00.png`；动画从 00 开始。保留原始大图、调色板 PNG、导出逻辑分辨率 PNG 和源提示词。

所有帧画布大小固定、透明边界至少 2 逻辑像素、Alpha 只能为 0 或 255。地面单位的 `pivot = bottom-center`，飞行单位的 `pivot = center`，投射物为 `center`。不要把脚底火花、阴影或地面装饰烘焙到角色本体。

## 本次库的内容

- `art-manifest.json`：覆盖现行图集全部逻辑资产的生产规格。
- `prompts/`：可复制到其他 AI 的分组提示词，含负面约束与动画关键帧要求。
- `generated/`：本次生成的原创母版/概念板，供重绘与风格锁定；不是可直接运行的 sprite atlas。
- `licenses/REFERENCE_SOURCES.md`：只记录参考方法和许可线索，不把第三方素材混入本资源库。
